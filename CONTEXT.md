# AthiDuo

A personal macOS utility that turns one desktop snapshot into a lid-driven visual fold.

## Language

**Reference Angle**:
The currently calibrated open-lid angle considered visually unchanged.
_Avoid_: resting threshold, clear angle

**Tracking**:
The ready state in which AthiDuo observes a valid lid-angle reading.
_Avoid_: recording, monitoring session

**Duo Effect**:
The single bottom-hinged perspective and blur transform applied to a desktop snapshot.
_Avoid_: theme, animation preset

**Held Pose**:
The static transformed snapshot that remains visible after lid movement stops.
_Avoid_: frozen desktop, screensaver

**Rearm Zone**:
The small range around the Reference Angle that enables Tracking after a manual dismissal.
_Avoid_: reset, cooldown
